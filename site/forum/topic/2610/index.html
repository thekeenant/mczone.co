Creating a Map Thread by ObsidianFire99

ObsidianFire99

Posted: 2 months ago
Edited: 2 months ago
So you’ve got a great map and want to share it with the community. Here’s how. (Note, this guide is for Windows 7. The process will be similar on other OSes)

  1. Take screenshots – Hit F2 in game to take screenshots and remember to do so with your GUI turned off by hitting F1 to make them look nicer. Also remember to take pictures of your default kits for the players. The more pictures you take the better.
  2. Upload the Pictures – Navigate to your AppData folder. If you don’t already know how do Windows – R to open the Run Dialogue. Type %appdata% in the box and hit enter. You should find a folder called Roaming if you aren’t already in it. Then find a folder called .minecraft in that. This is the directory where minecraft is installed. In the folder called screenshots are all the pictures you took. Now open a browser and go to imgur.com – this is where most MC Zone players host their images. Sign up for a free account and go to the images tab in the top right corner. Select the images you want in the screenshots folder and drag them on top of your browser window. If this doesn’t start an upload process you need to manually upload them by clicking the upload button and finding your screenshots folder again. Now go to the albums tab, create a new album and give it a name and layout. Go to Non-Album images and select all the images you want, and hit save. Congratulations!
  3. Create a map download – Go to the .minecraft folder and go into the saves folder. Make sure you do not have the minecraft map open in minecraft. Download 7-Zip (7zip.com) if you don’t already have your own archiver of choice. Right click on your map folder in the saves folder and click the 7-zip option, then hit Add to Archive. Don’t be daunted by the settings and just click OK. Once it has finished zipping up the folder you should see a zip file in the saves folder. I use Dropbox (dropbox.com) to host files. Go to Dropbox, and if you don’t have an account sign up. Now drag the zip file into your browser to upload it.
  4. Create a Thread – Hit the create thread button in the Map Releases Forum. First give your thread a name. It should be in the format:
    [Game it’s for] Map Name [Gamemode if applicable]
    For example [Nebula]Waterfalls[CTM] or [The Walls]Desert. Then do the description. It should introduce them map and give some key specification (Team colours, Number of Monuments etc.) Also you need to give a Download Link. Don’t say “I’ll only give the link to an admin so it doesn’t get copied” etc. If you have the pictures then you can prove if anyone claims the map to be their own. Go back to your Dropbox page and click the link button next to your file. Copy the address it sends you to and paste it in the thread. You should also provide a link to the Imgur gallery you are using. Now, hit the images tab in Imgur. Choose some pictures you want to display on the thread and click on them. Copy the direct link, and then click the image button in the thread editor. Paste in the URL and click Insert Image. Don’t overdo it, use 1 or 2 images that show an overview of the map so if people want to see more they can by clicking on the Imgur gallery link or by downloading the map.
Congratulations! You have created a great map thread. Now admins are much more likely to select it and you will get more feedback as well.
