NOTE: This is not the official system that wil be used, just one that I thought would be nice to suggest.


This is how I think the new currency system should work
First off, I think the new currency should be a premium currency - Only attainable through voting(?) and purchasing using real money.
This can then be used to buy kits or other in game advantages.
This system allows players to buy, say, 10,000 premium credits which then can be used to buy different priced kits depending on which mini-game you buy them for.
In addition to this, I think that we should have a non premium currency, attainable through kills, monument breaks, voting(?)  and winning a game ( Last one not on nebula or nexus). These non premium credits can then be used to purchase temporary kits, or temporary in game items.
Although this system is probably different from the new system coming up, which I don't know much about, I hope that it is taken into consideration by Funky.
Any suggestions or changes welcome.
-Thanks.
